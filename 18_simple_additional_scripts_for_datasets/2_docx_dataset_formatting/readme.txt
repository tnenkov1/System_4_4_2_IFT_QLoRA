Purpose: Converts unformatted text into .docx formatted text for fine-tuning.

This .docx file contains heading and text underneath it. 

To be used, it must be converted via the python script for lmft or ift, which generates examples.

The formatting of the text is done according to rules in the script followed by the chosen language model.

It is recommended to use a language model that has at least 7 B parameters in order to arrange the text correctly.

There is a probability for unformatted to be generated, so the output needs to be checked after that.
